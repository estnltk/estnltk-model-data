## Verb-object case conflicts dataset

### Object conflicts rules

1. Any *olema*-verb construction cannot have grammatical object
2. Other verb constructions that cannot have a grammatical object, specified by a list
3. Instances, where verb construction has only one main dependant, the dependant cannot be obj (has to be nsubj)
4. Grammatical object in singular nominative case can only occur with verb construction in imperative mood
5. Grammatical object's possible part-of-speeches are:
 - S or H (most common)
 - P
 - Y
 - A or N (less common)

## Dataset description

Dataset can be used to evaluate model's performance in following previously listed rules. Fields with value `CHECK` are to be validated. The sentences were chosen [randomly](https://github.com/estnltk/syntax_experiments/blob/dfa743b6c0e214af34bf0a306fd4d5f3587cfe85/workflows/004_analysis_of_known_verb_rection_patterns/005_categorizing_syntax_morphology_conflicts/verbs_obj_cases/verb_obj_cases_filtering.ipynb). Dataset was generated by Annely-Maria Liivas in 2026.
